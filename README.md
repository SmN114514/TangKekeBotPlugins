# TangKekeBotPlugins

唐可可 Bot 插件集 —— 符合上海宝宝体质的插件。

为 QQ Agent 编写的插件。这些代码为唐可可高度定制，但改起来很容易，懂的朋友一目了然。

---

## 这是什么

这里放的是我给自己养的 QQ 机器人「唐可可」写的插件。

唐可可是一个混在 QQ 群里的 AI 角色。她有自己的性格、声音、记忆，会聊天、会发动态、会自己判断什么时候该说话。

这个仓库里的代码，都是围绕她定制的。但底层用的是 QQ Agent 的标准插件机制，所以你拿去做别的角色，改起来也不难。

## 怎么用

1. 把插件目录放进 QQ Agent 的 `plugins/` 或 `skills/` 下
2. 按各插件自己的 `plugin.json` / `skill.json` 填配置
3. 重启（或开着开发模式热重载）

QQ Agent 的插件分两类：

- **`plugins/`**：确定性型，满足条件必然执行，不经过模型
- **`skills/`**：LLM 型，注册工具，由模型自己判断什么时候用

具体差异看各插件的清单文件和 QQ Agent 的开发文档。

---

## 注意

- 这些插件是为唐可可定制的，**不是通用工具**
- 里面有些配置项（比如作者白名单、音色 id、图库路径）是绑在唐可可身上的，换角色要改
- 部分插件需要外部依赖（API key、Cookie、本地文件夹），不配好不会生效
- 代码写得不一定优雅，但能用
